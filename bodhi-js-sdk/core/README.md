# @bodhiapp/bodhi-js-core

Core types and interfaces for Bodhi Browser SDK.

## Installation

```bash
npm install @bodhiapp/bodhi-js-core
```

## Usage

```typescript
import { ClientState, ApiResponseResult } from '@bodhiapp/bodhi-js-core';
```

## Documentation

See [bodhi-browser/bodhi-js-sdk](https://github.com/BodhiSearch/bodhi-browser/tree/main/bodhi-js-sdk) for complete documentation.
