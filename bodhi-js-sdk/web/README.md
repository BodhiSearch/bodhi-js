# @bodhiapp/bodhi-js

Web SDK for Bodhi Browser - `window.bodhiext` communication.

## Installation

```bash
npm install @bodhiapp/bodhi-js
```

## Usage

```typescript
import { WebUIClient } from '@bodhiapp/bodhi-js';

const client = new WebUIClient('your-client-id');
await client.init();
```
